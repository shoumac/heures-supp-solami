# HS SOLAMI + CHEF PV — V4

Cette version reprend l’application HS Solami fournie et conserve son design noir et or, son logo et les fonctions historiques d’heures supplémentaires. Elle ajoute un espace « Chef PV » pour la gestion de chantier, de l’équipe, du matériel, de la sécurité, de l’aide technique, de la formation et des rapports.

## Démarrage
1. Décompresser le ZIP.
2. Ouvrir `heures-supp-solami-main/index.html` dans Chrome, Edge ou Firefox.
3. Sur GitHub Pages, déposer les fichiers du dossier dans le dépôt comme d’habitude.

## Données
- Les heures restent dans la clé locale `hs_solami`.
- Les données Chef PV utilisent une clé séparée `hs_solami_chef_pv_v1`, afin de ne pas écraser l’historique existant.
- Les données restent locales à ce navigateur/appareil : pas encore de comptes ni de synchronisation multi-appareils.
- Les rapports peuvent être imprimés puis enregistrés en PDF via la fenêtre d’impression du navigateur.

## Sécurité
Les fiches techniques sont des rappels généraux et ne remplacent ni les procédures internes, ni les notices fabricants, ni les normes, ni la formation/habilitation électrique.
