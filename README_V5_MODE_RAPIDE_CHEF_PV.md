# HS Solami + Chef PV — V5 Mode rapide

## Nouveautés Chef PV
- Parcours terrain simplifié : checklist matériel et checklist sécurité à cocher.
- Plus besoin de saisir le nom du matériel, les quantités ou le briefing pour préparer la journée.
- Le seul champ libre du parcours rapide est le rapport de fin de chantier.
- Le compte rendu généré récapitule les cases cochées et les points non cochés, puis peut être imprimé ou enregistré en PDF depuis le navigateur.
- Les outils précédents (gestion des chantiers, équipe, fiches techniques et progression de formation) restent accessibles via « Outils avancés ».
- Le thème noir et or est conservé.

## Données
- Les heures supplémentaires restent dans leur clé de stockage historique `hs_solami`.
- Les données Chef PV restent séparées dans `hs_solami_chef_pv_v1`.
- Les nouvelles cases rapides sont enregistrées localement dans le navigateur/appareil.
- Cette version ne synchronise pas automatiquement les données entre appareils.

## Installation
Remplacer les fichiers du dépôt GitHub Pages par ceux du dossier `heures-supp-solami-main` uniquement après avoir testé la version localement. Ne pas supprimer les données du navigateur : les données d'heures sont conservées dans le stockage local existant.

Les checklists sont des aides-mémoires : elles ne remplacent pas les procédures de sécurité, les évaluations de risques, les plans du chantier ou les habilitations requises.
